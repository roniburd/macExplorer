    Finder, with the good parts of Explorer.

    MacExplorer is a native file manager for macOS 26. Cut and paste that moves files, an address bar you can type in, a folder tree, and folder sizes, in a window that still feels like a Mac.

    Download Compare with Finder Free and open source. Beta.

    Why we built it

    Lots of people move between a Windows PC at work and a Mac at home, or switched after years of File Explorer. Finder does a lot well. But a few things you do every day are harder than they need to be: moving files, typing a path, seeing where you are in the tree, finding out what's big.

    We kept the Mac parts (Quick Look, tags, the sidebar, Liquid Glass, the ⌘ shortcuts) and borrowed the Explorer ideas that make those everyday jobs quicker. It's AppKit, not a web view, and it opens folders with 100,000 files without stalling.

    Cut and paste that moves files

    • ⌘X marks the selection. It shows greyed until you paste. Esc cancels.
    • ⌘V in another folder moves them, with undo. Conflicts get one answer for the whole batch.
    • Finder's ⌥⌘V still works too.

    An address bar you can type in

    • It shows a breadcrumb. Click it, or press ⌘L, and it becomes a text field.
    • Paste a path, use ~, pick from suggestions. Each crumb has a menu of its sibling folders.
    • You're using one now: click the bar above and type.

    A folder tree, and what's taking the space

    • The tree under the sidebar opens to the folder you're in. Arrow keys expand and collapse it.
    • View › Calculate Folder Sizes fills in sizes from a background scan. Hard links count once, iCloud files aren't downloaded.
    • The status bar shows the selection's size and the free space.

    Tabs, views, and groups

    • Native tabs: ⌘T, middle-click a folder, or drop one on ＋.
    • Details, Icons and Columns. Each folder remembers its own view.
    • Group by Kind, Date Modified, Size or Name, with groups you can collapse.

    Still a Mac

    • Space for Quick Look. Return opens, as in Explorer; F2 renames. Prefer Finder's Return-renames? It's a setting.
    • ⌘⌫ moves to the Trash, and every file operation can be undone.
    • Finder tags, the macOS 26 sidebar and toolbar, dark mode, VoiceOver.
    • It can't take over “Show in Finder” in other apps or Open/Save panels. macOS doesn't allow that.
