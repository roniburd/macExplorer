      ⌘L

      Type where you want to go.

      The address bar is a breadcrumb until you click it or press ⌘L. Then it's a text field: paste a path, use ~, pick a suggestion. Each crumb opens a menu of its sibling folders.

      Finder: the path bar is read-only, and Go to Folder (⇧⌘G) is a separate sheet.

      View › Calculate Folder Sizes

      See which folder is big.

      Sizes fill in from a background scan, are cached, and stay current as files change. The tree under the sidebar opens to wherever you are, and the status bar shows what you've selected and how much space is left.

      Finder: folders show “--”, “Calculate all sizes” is slow, and the sidebar is a flat list.

      ⌘T

      Tabs, and a mouse that works.

      Native macOS tabs. Middle-click a folder to open it in a new tab. The back and forward buttons on your mouse go back and forward. Right-drag asks whether to copy, move or make an alias.

      Finder: mouse side buttons do nothing.

      ⇧⌘C

      Copy the path

      Or Copy Path As ▸ ~ path, file URL, name, quoted for the shell. Finder hides it behind Option.

      ⌘I

      Properties

      Live size and file count, a Permissions tab. Opens one window per item.

      F2

      Rename

      F2 renames and Return opens, as in Explorer. Want Return to rename, as in Finder? It's a setting.

      space

      Quick Look

      Unchanged from Finder, arrow keys included.

      ⌘123

      Views

      Details, Icons, Columns. Each folder remembers its own, without .DS_Store files.

      ⌘Z

      Undo

      Every move, rename, copy and trash can be undone.

      Why?

      Because a lot of us use Windows at work and a Mac at home, or switched after years of File Explorer, and a few everyday things never got easier on the Mac: moving files, typing a path, seeing the tree, finding what's big.

      MacExplorer is built with AppKit, so it looks and behaves like a Mac app on macOS 26, and it's tuned for folders with 100,000 files. It borrows Explorer's ideas, not its look.

      It can't replace Finder system-wide: “Show in Finder” in other apps, the Dock icon and Open/Save panels still use Finder. Cut here and paste in Finder makes a copy.

      Get MacExplorer

      Download the .dmg
      brew install --cask roniburd/macexplorer/macexplorer

      Free, MIT-licensed, updates itself. Needs macOS 26 Tahoe. Not notarized yet: if macOS won't open it the first time, run xattr -dr com.apple.quarantine /Applications/MacExplorer.app once.
